An exercise only pays off if its actions get done. Every action from every report lands in **Admin → Improvement plan**, for the organization's Exercise Program Manager.

<Screen name="improvement-plan" alt="Admin, Improvement plan: the actions of the organization's reports" />

## Follow up

The list shows the soonest due first. Filter it by status, overdue, re-test or text. An action is **overdue** when its date has passed and it isn't done or cancelled. The Admin dashboard counts open and overdue actions.

Updating an action's status, note or due date doesn't reopen a final report.

## Re-test

Link an action to a later exercise that tests it again, and optionally to one of its objectives. Use the **Re-tested in** column, in the report's plan or in Admin. The later exercise shows the actions it re-tests, and the report's PDF says where each one was re-tested.

If that exercise is deleted, the link is removed and the action stays.
