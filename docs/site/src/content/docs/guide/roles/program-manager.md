You look after the organization's exercise programme as a whole: which exercises happen, and whether their improvements get done. You work in **Admin**.

You can read and delete the organization's exercises, but you design only from a seat on an exercise's team, with the Exercise Planner role. Whoever founds an organization holds both roles; an instance administrator who creates one names its first Exercise Program Manager, and Exercise Program Managers grant the role to others.

**Your tasks:**

- [Manage people, roles and allowed domains](/guide/administration/)
- [Keep the organization's library](/guide/design/library/)
- [Follow up the improvement plan](/guide/improve/)
