Open **Players**. It has three tabs: **Confirmed**, **Pending** and **Invitations**.

There are two ways in.

## By email

If the instance sends email, you can invite up to 50 addresses at a time from **Invitations**. Each gets a personal link, valid for 14 days. The link grants the exercise at once, because it proves its holder reads that mailbox. Someone without an account creates one from the link.

You can resend or withdraw each invitation.

## With a join code

Create an invitation in **Invitations**, with an optional description, limit and expiry of up to a year. Share the code however you like.

A join code isn't a secret, so anyone holding it only gets a **pending** request. You approve or reject each one in **Pending**. You can revoke a code at any time.

## Confirmed Players

**Confirmed** lists the exercise's Players, how each one joined and their last sign-in. From there you can remove a Player. Requests to leave an exercise wait in **Pending**, with the requests to join.
